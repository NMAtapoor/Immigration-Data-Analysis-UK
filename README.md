# Immigration-Data-Analysis-UK
Immigration-Data-Analysis-UK explores UK immigration patterns across legal and illegal routes. It analyses migration from different countries, including work and study sponsorships and irregular entry, transforming raw data into clear insights and visualizations to understand evolving migration trends.

# Project Plan:

## Project Requirement as an EPIC:

``` text
As a CUSTOMER I want the UK immigration data is identified, downloaded, and then extracted from excel files into CSVs, and properly transformed, cleaned, and stored locally into project. The cleaned data, then be analyzed, the immigration pattern is identified, and presented visually to simply provide a clear perspective and insight on migration entry into UK from various routes. 

```
